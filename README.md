# Cubey & Canon

A browser-based 3D action-platformer built with three.js and Vite.

## Publish to GitHub Pages

The full game source and assets are in `cubey-and-canon-source-github-actions.zip`, provided in ChatGPT. Download that ZIP to your PC. Then either upload its **contents** to this repository or follow the PowerShell commands provided in the same conversation to push the ZIP contents.

The ZIP includes `.github/workflows/deploy-pages.yml`, which installs dependencies, builds the game, and deploys it using GitHub Actions.

After committing the source, enable **Settings → Pages → Build and deployment → GitHub Actions**. The game URL will be:

https://mindflexor.github.io/cubey-and-canon/

This repository is initialized, but the playable game and assets must be uploaded before it can go live.
